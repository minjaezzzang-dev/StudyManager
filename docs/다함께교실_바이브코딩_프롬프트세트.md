# 다함께교실 — 기능별 바이브코딩 프롬프트 세트 (4단계) v1.0

학생이 Trae/Cursor/Claude 등에 **순서대로 붙여넣어** 앱을 만드는 한국어 명령어 모음. 작년 보고서의 "프롬프트 명령어" 방식 계승. 스택: 앱 React Native(Expo) \+ 백엔드 Supabase(Edge Functions/Postgres/pgvector) \+ 외부 AI(Vision·OpenAI·음성). **API 키는 전부 Edge Function 환경변수에만.**

## 사용 규칙 (학생 안내)

1. 한 번에 한 프롬프트씩. 결과를 **에뮬레이터/Expo Go로 확인**한 뒤 다음으로.  
2. 오류가 나면 오류 메시지를 **그대로 복사해서** "다음 오류를 해결해줘: ..." 로 요청.  
3. 새 화면은 항상 "어떤 버튼을 누르면 어디로 간다"까지 적기.  
4. 키·비밀번호는 절대 코드/채팅에 붙여넣지 않기.

---

## STEP 0\. 프로젝트 맥락 주입 (맨 처음 1회)

나는 '다함께교실'이라는 교육용 앱을 만든다. 이주배경학생의 학습장벽(언어)을 돕는 앱이다.

스택은 앱=React Native(Expo)+TypeScript, 백엔드=Supabase(Edge Functions, Postgres, pgvector),

AI=Google Vision(OCR)/OpenAI(번역·LLM)/클라우드 음성(STT·TTS)이다.

중요 규칙: 모든 AI 호출과 API 키는 Supabase Edge Functions(서버)에서만 처리하고,

앱에는 절대 API 키를 넣지 않는다. 클린 아키텍처로 화면/유스케이스/통신 계층을 분리한다.

앞으로 이 원칙을 지켜서 코드를 작성해줘. 이해했으면 폴더 구조부터 제안해줘.

---

## M1. 환경·보안·로그인

### 0-1 프로젝트 생성

Expo \+ TypeScript로 'dahamkke-mobile' 프로젝트를 만드는 명령어와 폴더 구조를 알려줘.

화면은 src/presentation/screens, 통신은 src/infrastructure, 규칙/타입은 src/domain에 둔다.

React Navigation으로 화면 이동을 설정해줘.

### 0-2 Supabase 연결 \+ 환경변수

앱에서 Supabase에 연결하는 supabaseClient.ts를 만들어줘.

Supabase URL과 anon key는 app.config의 환경변수(extra)로 불러오고, 코드에 직접 쓰지 마.

service\_role 키나 OpenAI 키는 앱에 절대 넣지 말고 서버(Edge Function)에서만 쓸 거야.

### 0-3 로그인/회원가입

Supabase Auth(이메일/비밀번호)로 로그인 화면(LoginScreen)과 회원가입 화면을 만들어줘.

회원가입 시 이름과 모국어(러시아어/중국어/베트남어/우즈베크어/카자흐어/한국어 중 선택)를 받아

profiles 테이블에 저장해줘. 로그인 성공하면 MainScreen으로 이동한다.

비밀번호는 8자 이상 유효성 검사를 넣어줘.

---

## M2. 메인·번역·통역

### 1-0 메인 화면

MainScreen을 만들어줘. 상단에 "환영합니다, {로그인한 사용자 이름}님"과 언어 선택 드롭다운(6개 언어).

아래에 기능 버튼 6개: ①교과서 번역 ②실시간 통역 ③토론 친구 ④인물 인터뷰 ⑤가정통신문 번역 ⑥학습 기록.

자주 쓰는 ①②를 가장 크게/위에 배치. 각 버튼은 해당 화면으로 이동한다.

### 1-1 Edge Function `/translate` (서버, 키 보관)

Supabase Edge Function 'translate'를 만들어줘.

입력: { imageBase64 또는 text, targetLang }.

처리: imageBase64가 있으면 Google Vision API로 OCR하여 한국어 원문을 얻고,

그 텍스트(또는 입력 text)를 OpenAI로 targetLang으로 번역한다.

OpenAI 키와 Vision 키는 함수 환경변수(Deno.env)에서 읽고 절대 응답에 노출하지 마.

출력: { sourceText, resultText }. 요청에는 Supabase JWT 인증을 요구해줘.

### 1-2 교과서 번역 화면(F1)

TranslateScreen을 만들어줘. expo-camera/expo-image-picker로 사진을 찍거나 고른 뒤 미리보기.

'텍스트 추출' 버튼 → translate 함수 호출(이미지) → 한국어 원문 표시(수정 가능 TextInput).

'번역' 버튼 → 선택 언어로 번역 → 원문과 번역을 위/아래로 나란히 표시.

번역 중에는 '번역 중...' 로딩을 보여줘. 결과를 저장하는 버튼도 넣어줘(translations 테이블).

### 2-1 Edge Function `/interpret`

Edge Function 'interpret'를 만들어줘.

입력: { audioBase64, fromLang, toLang }. 처리: 음성→텍스트(STT) → toLang으로 번역 → TTS 음성 생성.

출력: { sourceText, resultText, audioUrl }. 키는 환경변수에서만 사용.

### 2-2 실시간 통역 화면(F2)

InterpretScreen을 만들어줘. expo-av로 마이크 녹음.

버튼 2개: \[한국어 말하기\](ko→사용자언어), \[내 언어 말하기\](사용자언어→ko).

버튼을 누르고 말하면 interpret 함수를 호출해 텍스트로 보여주고, 결과 음성을 자동 재생.

대화는 말풍선으로 누적(한국어=왼쪽, 외국어=오른쪽). 토의 상황을 가정해 번갈아 사용할 수 있게.

## M3. 에이전트 — 토론·RAG·인터뷰

### 3-1 RAG 색인 함수(F5, 교사용)

Edge Function 'rag-ingest'를 만들어줘. 입력: { textbookId, rawText }(교사만 호출).

rawText를 문단 단위로 나누고 각 문단을 OpenAI 임베딩으로 변환해 text\_chunks 테이블에

(textbook\_id, content, embedding, chunk\_order)로 저장해줘. 출력: { chunks: 개수 }.

### 3-2 토론 친구(F3)

Edge Function 'chat-debate'와 DebateScreen을 만들어줘.

입력: { topic, message, userLang, history }. 처리: 가상의 '초등학생 한국인 친구'가

초등 눈높이 한국어로 자기 의견을 말하고 사용자의 주장에 반응한다(존중하는 토론 태도).

사용자가 자기 언어로 쓰면 통역해서 토론이 이어지게 한다.

출력: { replyKo, replyUser(=userLang 번역) }. 말풍선 대화로 표시.

### 3-3 인물 인터뷰 \+ RAG(F4)

Edge Function 'persona'와 PersonaScreen을 만들어줘.

입력: { personaId, question, userLang, history }.

처리: ①question을 임베딩해 match\_chunks로 해당 교과서 근거 문단 4개를 찾는다

②personas.system\_prompt \+ 근거 문단 \+ 질문으로 프롬프트를 구성해 인물이 1인칭으로 답한다

③답변을 userLang으로 병기 번역 ④대화를 dialogs에 저장.

출력: { answer, sources:\[단원/문단\] }. 화면 하단에 "근거: ..."를 표시.

교과서에 없는 내용은 "이건 제 상상이에요"라고 답하도록 system\_prompt에 규정해줘.

### 3-4 페르소나 등록(교사)

교사가 교과서 인물 페르소나를 등록하는 화면을 만들어줘.

인물 이름과 system\_prompt(역할/말투/시대 제약)를 입력해 personas 테이블에 저장.

예시 프롬프트도 하나 채워줘(예: 흥부 \- "너는 흥부야. 착하고 가난하지만 따뜻하게,

어린이에게 옛날 말투로 답해. 교과서 내용 밖은 상상이라고 말해").

## M4. 확장

### 4-1 학습 기록(F6)

RecordScreen을 만들어줘. 로그인한 사용자의 translations와 dialogs를 리스트로 보여주고,

항목을 누르면 상세 팝업. RLS로 본인 데이터만 보이는지 확인해줘.

'복습 도움' 버튼을 누르면 저장된 기록을 바탕으로 AI가 어려워한 표현을 짚어 조언하게 해줘.

### 4-2 가정통신문 번역(F7)

Edge Function 'notice-translate'와 NoticeScreen을 만들어줘.

입력: { imageBase64, targetLangs\[\] }. 처리: OCR → 각 언어로 번역 \+ 핵심요약(날짜·준비물·제출기한 추출).

화면: 가정통신문 사진 업로드 → 언어 선택 → 번역 결과와 요약 표시 → 공유용 QR코드 생성.

## M6. Reachy Mini 로봇(하이브리드)

(로봇 측 Python) Reachy Mini에서 다음을 구현해줘:

1\) 호출어 감지 후 마이크로 음성을 녹음(온디바이스 STT로 텍스트화).

2\) 그 텍스트를 우리 Supabase Edge Function 'interpret'(또는 'persona')로 보내 답변을 받는다.

3\) 받은 답변을 스피커로 TTS 재생하고, 말할 때 머리/안테나가 움직이게 한다.

4\) 질문 언어(한국어/베트남어/카자흐어/중국어)를 감지해 같은 언어로 답하게 한다.

API 키는 로봇 코드에 넣지 말고 Edge Function이 처리한다.

경량 온디바이스 모델이 필요하면 Gemma 3n을 STT/간단 응답에 사용. 무거운 번역·대화는 서버.
