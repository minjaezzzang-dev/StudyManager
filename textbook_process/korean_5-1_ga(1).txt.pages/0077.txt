3. 과거, 현재, 미래를 나타내는 시간 표현을 알아봅시다.

(1) 문장이 과거, 현재, 미래 가운데 무엇을 나타내는지 생각해 보고 알맞은 칸에 O표를 해 보세요.

| 문장 | 과거 | 현재 | 미래 |
| :--- | :--- | :--- | :--- |
| 물수리는 풀숲에 집을 넣어 날씨로 날개로 날뜀으로 물고기를 옮겨놓고 앞으로 날아온다. | | | |
| 이 풀수리는 스프롤랜드로부터 온 힘을 다해 날아온다. | | | |
| 새끼들은 충분히 크고 작하게 자라서 8일까지 풀고기 알을 낳는 법을 익을 예정이다. | | | |
| 풀수리는 풀고기를 잡기 위해 바다 위를 날아다닌다. | | | |
| 4월말이던 태안의년 호수 근처에 도착하여 책을 찾으러 갔다. | | | |
| 그들은 동자를 만들고 새로운 가정을 꾸밀 것이다. | | | |

과거, 현재, 미래의 시간을 나타내는 말을 시간 표현이라고해요.

(2) (1)에서 각 문장이 과거, 현재, 미래를 나타낸다고 생각한 까닭을 친구들과 이야기하며 보세요.

'배웠던'는 배우고-'어-'를 써서 과거를 나타냈어요.

'날아오른다는'는 '날-'을 써서 현재를 나타냈어요.
