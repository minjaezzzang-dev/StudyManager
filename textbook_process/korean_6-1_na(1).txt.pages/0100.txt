3. 주장하는 글 쓰기 과정을 점검하는 질문을 만들어 봅시다. <10점> 활용하세요.

(1) 계획하기 과정을 점검하는 질문을 만들어 보세요.

| 쓰기 과정 | 점검 질문 |
| --- | --- |
| 계획하기 | 글을 쓰는 목적이 무엇인지 정했나요? |
| | 글이 주제를 무엇인지 정했나요? |
| | 글의 주제는 글을 쓰는 목적과 관련 있나요? |
| | 필요한지 여부는 못 |
| | 글을 읽을 사람이 관심을 가질 만한 것이 무엇인지 생각했나요? |

(2) 내용 완성하기 과정을 점검하는 질문을 만들어 보세요.

| 쓰기 과정 | 점검 질문 |
| --- | --- |
| 내용 완성하기 | 글에 쓸 내용을 생각하려고 내가 이거 읽고 있는 것을 떠올렸나요? |
| | 필요한지 여부는 못 |
| | 글의 내용은 주제와 관련 있나요? |
| | 글의 내용은 읽는 사람에게 도움이 되나요? |
